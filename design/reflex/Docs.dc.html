LIFECYCLE
teacher gates pass → shadow 200 calls or 24 h → assist
↺ drift on the holdout slice, or a new lineage → teacher
teacher · every call goes to the LLM. shadow · the LLM answers every call. The student predicts too, and both are logged. assist · calls where every field clears min_confidence are served locally. Everything else, plus the holdout slice, goes to the LLM.
gargi report route_ticket --out report.html · local demo run
CLI REFERENCE
gargi scan PATH [--json] [--volume FILE]Find swappable LLM call sites and estimate monthly savings
gargi initCreate ./.gargi/ and print the DB path
gargi replay --app mod[:fn] --input rows.jsonlRun the teacher over historical inputs; resumable
gargi train NAME [--no-promote] [--new-lineage]Train and gate; exit 0 = passed, 2 = gates failed, 1 = error
gargi status [NAME] [--json]State, rows, swap rate, agreement, ECE, p50, estimated savings
gargi review NAME [--limit 20]Disagreements and low-confidence rows worth labelling
gargi correct ID --field F --value VRecord a human label, validated against the schema
gargi promote NAME · gargi demote NAMEManual overrides; every override is recorded
gargi report NAME --out report.htmlSwap rate and agreement over time, savings, lifecycle
gargi proxy [--port 8787] [--upstream URL]Run an OpenAI-compatible proxy server
